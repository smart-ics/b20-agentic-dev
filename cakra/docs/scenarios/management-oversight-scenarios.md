# Management Oversight Scenarios

## SC-MGT-001

```text id="sc-mgt-001"
Scenario ID:
SC-MGT-001

Scenario Name:
Management Reassigns Request

Primary Actor:
Management

Goal:
Change the ownership of a Request to another handler.

Related Domains:
Request
Organization

Trigger:
The Request needs to be reassigned due to workload, expertise, or priority.

Expected Outcome:
The Request Owner is changed to a different handler.
```
