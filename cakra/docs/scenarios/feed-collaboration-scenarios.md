# Feed Collaboration Scenarios

## SC-FCOL-001

```text id="sc-fcol-001"
Scenario ID:
SC-FCOL-001

Scenario Name:
Actor Comments on Operational Post

Primary Actor:
All Actors

Goal:
Contribute a comment to an operational discussion in the feed.

Related Domains:
Post

Trigger:
Actor observes a Post and has information, clarification, or perspective to contribute.

Expected Outcome:
Comment is recorded as part of the Post discussion and visible to all stakeholders.
```
